title: Steamworks
---

SwiftlyS2 ships generated server-side Steamworks bindings under `SwiftlyS2.Shared.SteamAPI` (`using SwiftlyS2.Shared.SteamAPI;`), covering identity, authorization, server metadata, license/Workshop checks, and Steam's async callback patterns, as static classes mirroring the native `ISteamGameServer*` interfaces - see <ApiRef name="SteamGameServer" />, <ApiRef name="SteamGameServerUtils" />, <ApiRef name="SteamGameServerUGC" /> and <ApiRef name="SteamGameServerStats" /> for the full member lists (or the Quick Reference table at the end for the class overview). The same namespace also exposes the game server handles and the callback registration types described below.

## Waiting for the Steam API

Steam callbacks aren't usable until the Steam API finishes activating - subscribe to `Core.Event.OnSteamAPIActivated` before touching any class above:

```csharp
public override void Load(bool hotReload)
{
    Core.Event.OnSteamAPIActivated += OnSteamApiActivated;
}

private void OnSteamApiActivated()
{
    var appId = SteamGameServerUtils.GetAppID();
    Core.Logger.LogInformation("Steam API ready, AppId={AppId}", appId.m_AppId);
}
```

<ApiRef name="InteropHelp" member="TestIfAvailableGameServer" /> is the synchronous equivalent: it throws an `InvalidOperationException` when the game server API isn't initialized yet, so it can be used as a guard from code that doesn't run off `OnSteamAPIActivated`.

## Converting Player IDs to Steam IDs

`IPlayer.SteamID` is a plain `ulong` - wrap it in <ApiRef name="CSteamID" /> before passing it to a Steam API call:

```csharp
IPlayer? player = Core.PlayerManager.GetPlayer(playerId);
if (player == null) return;

var steamId = new CSteamID(player.SteamID);
if (!steamId.IsValid() || !steamId.BIndividualAccount())
{
    Core.Logger.LogWarning("Invalid SteamID for slot {PlayerId}", playerId);
    return;
}
```

## Authorization Signals

`Core.Event.OnClientSteamAuthorize`/`OnClientSteamAuthorizeFail` fire once Steam confirms or rejects a connecting client:

```csharp
Core.Event.OnClientSteamAuthorize += @event =>
    Core.Logger.LogInformation("Steam auth OK for slot {PlayerId}", @event.PlayerId);

Core.Event.OnClientSteamAuthorizeFail += @event =>
    Core.Logger.LogWarning("Steam auth failed for slot {PlayerId}", @event.PlayerId);
```

```csharp
SteamGameServer.SetServerName("My Swiftly Server");

```

## Game Server Handles

The classes above go through the `ISteamGameServer*` interfaces - <ApiRef name="GameServer" /> holds the process-level accessors that don't need an interface instance:

```csharp
CSteamID serverSteamId = GameServer.GetSteamID();
HSteamPipe pipe = GameServer.GetHSteamPipe();
HSteamUser user = GameServer.GetHSteamUser();
bool secure = GameServer.BSecure();
```

| Member                                              | Signature                           | Returns                                        |
| --------------------------------------------------- | ----------------------------------- | ---------------------------------------------- |
| <ApiRef name="GameServer" member="GetSteamID" />     | `static CSteamID GetSteamID()`      | the Steam ID of the game server                |
| <ApiRef name="GameServer" member="GetHSteamPipe" />  | `static HSteamPipe GetHSteamPipe()` | the Steam pipe handle of the game server       |
| <ApiRef name="GameServer" member="GetHSteamUser" />  | `static HSteamUser GetHSteamUser()` | the Steam user handle of the game server       |
| <ApiRef name="GameServer" member="BSecure" />        | `static bool BSecure()`             | whether the game server is VAC-secured         |

```csharp
var result = SteamGameServer.UserHasLicenseForApp(steamId, appId);

if (result == EUserHasLicenseForAppResult.k_EUserHasLicenseResultHasLicense)

```

## Workshop Items

Use `SteamGameServerUGC` - not the client-side `SteamUGC` - for server-side Workshop queries:

```csharp
var fileId = new PublishedFileId_t(3070212801);
var state = (EItemState)SteamGameServerUGC.GetItemState(fileId);

if ((state & EItemState.k_EItemStateInstalled) == 0)
{
    SteamGameServerUGC.DownloadItem(fileId, bHighPriority: true);
}
```

Downloads complete asynchronously through a Steam callback struct - see below.

## Steam Callbacks and Call Results

Steam surfaces two async patterns: <ApiRef name="Callback`1" /> fires whenever a matching struct is posted; <ApiRef name="CallResult`1" /> is a one-shot result tied to a `SteamAPICall_t` from a request method. Both are `IDisposable` and both are constrained to a callback struct (`where T : struct`) - dispose them, typically in `Unload`.

<Tabs>
  <Tab label="Callback<T>">
    ```csharp
    private Callback<DownloadItemResult_t>? _downloadResult;

    public override void Load(bool hotReload)
    {
        _downloadResult = Callback<DownloadItemResult_t>.Create(OnDownloadItemResult);
    }

    public override void Unload()
    {
        _downloadResult?.Dispose();
    }

    private void OnDownloadItemResult(DownloadItemResult_t result)
    {
        if (result.m_eResult != EResult.k_EResultOK) return;

        SteamGameServerUGC.GetItemInstallInfo(
            result.m_nPublishedFileId, out ulong size, out string folder, 1024, out uint timestamp);
    }
    ```

  </Tab>
  <Tab label="CallResult<T>">
    ```csharp
    private CallResult<GSStatsReceived_t>? _statsResult;

    public void RequestStats(CSteamID steamId)
    {
        SteamAPICall_t call = SteamGameServerStats.RequestUserStats(steamId);
        _statsResult = CallResult<GSStatsReceived_t>.Create(call.m_SteamAPICall, OnStatsReceived);
    }

    private void OnStatsReceived(GSStatsReceived_t result, bool ioFailure)
    {
        if (ioFailure || result.m_eResult != EResult.k_EResultOK) return;

        if (SteamGameServerStats.GetUserStat(result.m_steamIDUser, "total_kills", out int kills))
            Core.Logger.LogInformation("kills={Kills}", kills);
    }
    ```

  </Tab>
</Tabs>

`Callback<T>` stays registered until you dispose it. `CallResult<T>` disposes itself right after its result fires, so keeping the instance in a field is only useful to cancel it early or to reuse it.

### Registration Members

| Member                                              | Signature                                                      | Notes                                                                                              |
| --------------------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| <ApiRef name="Callback`1" member="Create" />         | `static Callback<T> Create(Action<T> callback)`                 | creates and registers the handler in one step                                                     |
| <ApiRef name="Callback`1" member="Dispose" />        | `void Dispose()`                                                | unregisters the handler                                                                            |
| <ApiRef name="CallResult`1" member="Create" />       | `static CallResult<T> Create(ulong hAPICall, Action<T, bool> callback)` | `hAPICall` is the `SteamAPICall_t` handle, the callback receives the result struct and `ioFailure` |
| <ApiRef name="CallResult`1" member="Set" />          | `void Set(ulong hAPICall)`                                      | re-points an existing instance at another call handle, unregistering the previous one; pass `0` to only unregister |
| <ApiRef name="CallResult`1" member="Dispose" />      | `void Dispose()`                                                | cancels the pending call                                                                           |

<ApiRef name="CallResult`1" member="Set" /> is for reuse - e.g. a single stats call result that is re-pointed at every new `RequestUserStats` handle instead of allocating a `CallResult<T>` per request.

## Auth Sessions

To validate a client-provided auth ticket manually, use `BeginAuthSession`/`EndAuthSession` rather than the deprecated connect/disconnect variants:

```csharp
var authResult = SteamGameServer.BeginAuthSession(ticket, ticket.Length, steamId);
if (authResult != EBeginAuthSessionResult.k_EBeginAuthSessionResultOK)
{
    return;
}

// ... later, once the session ends ...
SteamGameServer.EndAuthSession(steamId);
```

## Helpers

- <ApiRef name="InteropHelp" /> - `TestIfAvailableGameServer()` throws when the game server API isn't initialized yet, see [Waiting for the Steam API](#waiting-for-the-steam-api).
- <ApiRef name="CallbackIdentities" /> - <ApiRef name="CallbackIdentities" member="GetCallbackIdentity" /> takes a callback struct `Type` and returns its numeric Steam callback ID (`int`), throwing when the struct carries no identity. Mostly useful for logging which callback fired.
- `Packsize` - `Packsize.value` is the `const int` pack size (`8` on Windows, `4` on other platforms) the generated Steam structs are declared with.
