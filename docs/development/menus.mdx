---
title: Menus (Deprecated)
---

SwiftlyS2 menus provide an interactive, per-player UI layer for settings, selections, and action flows, through `Core.MenusAPI` (<ApiRef name="IMenuManagerAPI" />).

<Callout type="warning">
    The classic menu API is deprecated: every interface, event args class and
    enum in `SwiftlyS2.Shared.Menus`, and `Core.MenusAPI` itself, is marked
    `[Obsolete]` and will be removed in a future version. Use `Core.Menu`
    (<ApiRef name="IMenuService" />) for new plugins - see
    [Menu System](/docs/development/menu-system).
</Callout>

## Recommended Workflow

1. Create a builder with `Core.MenusAPI.CreateBuilder()`.
2. Configure behavior (sound, freeze, auto-close, keybind overrides) and appearance (`builder.Design`).
3. Add options and call `Build()`.
4. Open and close through `Core.MenusAPI`.

The manager members below cover the whole lifecycle:

| Member                                                        | Description                                                                                                     |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| <ApiRef name="IMenuManagerAPI" member="CreateBuilder" />      | Creates a new <ApiRef name="IMenuBuilderAPI" />.                                                                |
| <ApiRef name="IMenuManagerAPI" member="CreateMenu" />         | Builds a menu directly from <ApiRef name="MenuConfiguration" />/<ApiRef name="MenuKeybindOverrides" /> objects. |
| <ApiRef name="IMenuManagerAPI" member="OpenMenuForPlayer" />  | Opens a menu for one player, closing any menu they already have open.                                           |
| <ApiRef name="IMenuManagerAPI" member="OpenMenu" />           | Opens a menu for every player.                                                                                  |
| <ApiRef name="IMenuManagerAPI" member="CloseMenuForPlayer" /> | Closes a specific menu for one player; no effect if the player does not have it open.                           |
| <ApiRef name="IMenuManagerAPI" member="CloseActiveMenu" />    | Closes whatever menu the player currently has open.                                                             |
| <ApiRef name="IMenuManagerAPI" member="CloseMenu" />          | Closes a menu for every player who has it open.                                                                 |
| <ApiRef name="IMenuManagerAPI" member="CloseAllMenus" />      | Closes every open menu for every player.                                                                        |
| <ApiRef name="IMenuManagerAPI" member="GetCurrentMenu" />     | Returns the player's active menu, or `null` if they have none open.                                             |

<ApiRef name="IMenuManagerAPI" member="Core" /> is the <ApiRef name="ISwiftlyCore" /> instance the manager belongs to, and <ApiRef name="IMenuManagerAPI" member="Configuration" /> exposes the resolved core menu settings as a <ApiRef name="MenuManagerConfiguration" />:

| Member                                                                          | Description                                                                      |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `NavigationPrefix` (`string`)                                                   | Prefix used for menu navigation commands.                                        |
| `InputMode` (`string`)                                                          | Input mode that determines how player input is captured for menu navigation.      |
| `ButtonsUse` / `ButtonsScroll` / `ButtonsScrollBack` / `ButtonsExit` (`string`) | Default button mappings for selecting, scrolling down, scrolling up and closing.  |
| `SoundUseName` / `SoundScrollName` / `SoundExitName` (`string`)                 | Sound played when selecting, scrolling or exiting.                                |
| `SoundUseVolume` / `SoundScrollVolume` / `SoundExitVolume` (`float`)            | Volume of the corresponding sound (`0.0` to `1.0`).                              |
| `ItemsPerPage` (`int`)                                                          | Maximum items per page. Menus exceeding this limit are paginated.                 |

All of these come from `Menu` in `configs/core.jsonc` - see [Core Configuration](/docs/resources/core-config).

## Builder Configuration

Every call under `.Design` returns back to the builder, so chain `.Design.` again for each design call:

```csharp
var menu = Core.MenusAPI.CreateBuilder()
    .EnableSound()
    .SetPlayerFrozen(false)
    .SetAutoCloseDelay(0f)
    .SetSelectButton(KeyBind.E | KeyBind.Mouse1) // KeyBind is a [Flags] enum
    .SetMoveForwardButton(KeyBind.W)
    .SetMoveBackwardButton(KeyBind.S)
    .SetExitButton(KeyBind.Esc)
    .AddExtraButton(KeyBind.R, "Reset", (p, m) =>
    {
        p.SendChat("Reset action executed.");
    })
    .Design.SetMenuTitle("Gameplay Settings")
    .Design.SetMenuTitleItemCountVisible(true)
    .Design.SetMenuFooterVisible(true)
    .Design.SetCommentVisible(true)
    .Design.SetDefaultComment("Use W/S to move and E to select")
    .Design.SetMaxVisibleItems(5)
    .Design.SetGlobalScrollStyle(MenuOptionScrollStyle.WaitingCenter)
    .Build();

Core.MenusAPI.OpenMenuForPlayer(player, menu);
```

<Callout type="info">
    `MaxVisibleItems` only accepts `[1, 5]` or `-1` (falls back to
    `ItemsPerPage` in `configs/core.jsonc`, see [Core
    Configuration](/docs/resources/core-config)) - out-of-range values log an
    error and reset to `-1`.
</Callout>

Every <ApiRef name="IMenuBuilderAPI" /> method returns the builder for chaining, except <ApiRef name="IMenuBuilderAPI" member="Build" />:

| Method                                                                                                                                                                                                                                                                 | Description                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| <ApiRef name="IMenuBuilderAPI" member="Design" /> (`IMenuDesignAPI`)                                                                                                                                                                                                   | The design interface of this menu, see [Menu Design](#menu-design).                       |
| <ApiRef name="IMenuBuilderAPI" member="BindToParent" />(`IMenuAPI parent`)                                                                                                                                                                                             | Binds the menu to a parent menu, so closing it returns to that menu.                      |
| <ApiRef name="IMenuBuilderAPI" member="AddOption" />(`IMenuOption option`)                                                                                                                                                                                             | Adds an option to the menu.                                                               |
| <ApiRef name="IMenuBuilderAPI" member="EnableSound" /> / <ApiRef name="IMenuBuilderAPI" member="DisableSound" />                                                                                                                                                       | Turns interaction sounds on or off.                                                       |
| <ApiRef name="IMenuBuilderAPI" member="EnableExit" /> / <ApiRef name="IMenuBuilderAPI" member="DisableExit" />                                                                                                                                                         | Turns the exit button for this menu on or off.                                            |
| <ApiRef name="IMenuBuilderAPI" member="SetPlayerFrozen" />(`bool frozen = false`)                                                                                                                                                                                      | Freezes player movement while the menu is open.                                           |
| <ApiRef name="IMenuBuilderAPI" member="SetAutoCloseDelay" />(`float seconds = 0f`)                                                                                                                                                                                     | Closes the menu automatically after the given number of seconds; `0` disables auto-close. |
| <ApiRef name="IMenuBuilderAPI" member="SetSelectButton" /> / <ApiRef name="IMenuBuilderAPI" member="SetMoveForwardButton" /> / <ApiRef name="IMenuBuilderAPI" member="SetMoveBackwardButton" /> / <ApiRef name="IMenuBuilderAPI" member="SetExitButton" /> (`KeyBind`) | Overrides one navigation key bind of this menu. Combine keys with `\|`.                   |
| <ApiRef name="IMenuBuilderAPI" member="AddExtraButton" />(`KeyBind keyBind, string label, Action<IPlayer, IMenuAPI> action`)                                                                                                                                           | Adds a custom button that is shown in the menu footer and runs `action` when pressed.     |
| <ApiRef name="IMenuBuilderAPI" member="Build" />                                                                                                                                                                                                                       | Builds and returns the finished <ApiRef name="IMenuAPI" />.                               |

The `Set*Button` overrides replace the corresponding default from `Menu.Buttons` in `configs/core.jsonc`; a key bind that is not overridden keeps its default.

## Menu Design

`builder.Design` (<ApiRef name="IMenuDesignAPI" />) controls appearance. Like the builder, every call returns the builder:

| Method                                                                                                                                           | Description                                                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <ApiRef name="IMenuDesignAPI" member="SetMenuTitle" />(`string? title = null`)                                                                   | Title displayed at the top of the menu; `null` clears it.                                                                                                                                                             |
| <ApiRef name="IMenuDesignAPI" member="SetMenuTitleVisible" />(`bool visible = true`)                                                             | Shows or hides the title.                                                                                                                                                                                             |
| <ApiRef name="IMenuDesignAPI" member="SetMenuTitleItemCountVisible" />(`bool visible = true`)                                                    | Shows or hides the item count in the title.                                                                                                                                                                           |
| <ApiRef name="IMenuDesignAPI" member="SetMenuFooterVisible" />(`bool visible = true`)                                                            | Shows or hides the footer.                                                                                                                                                                                            |
| <ApiRef name="IMenuDesignAPI" member="SetCommentVisible" />(`bool visible = true`)                                                               | Shows or hides option comments.                                                                                                                                                                                       |
| <ApiRef name="IMenuDesignAPI" member="SetDefaultComment" />(`string comment`)                                                                    | Comment used for options that do not set their own.                                                                                                                                                                   |
| <ApiRef name="IMenuDesignAPI" member="SetMaxVisibleItems" />(`int count = 5`)                                                                    | Maximum number of options visible at once. Valid range is `[1, 5]`; menus with more options are paginated.                                                                                                            |
| <ApiRef name="IMenuDesignAPI" member="EnableAutoAdjustVisibleItems" /> / <ApiRef name="IMenuDesignAPI" member="DisableAutoAdjustVisibleItems" /> | Turns automatic adjustment of the visible item count on or off. When enabled, hiding the title or footer increases the effective visible count during rendering, without changing the `SetMaxVisibleItems` value.     |
| <ApiRef name="IMenuDesignAPI" member="SetGlobalScrollStyle" />(`MenuOptionScrollStyle style`)                                                    | Default scroll style for all options; individual options can override it.                                                                                                                                             |
| `SetNavigationMarkerColor` / `SetMenuFooterColor` / `SetVisualGuideLineColor` / `SetDisabledColor`                                               | Sets the color of navigation markers, the footer, the visual guide lines or disabled options. Each takes an overload for a hex string (`null` resets to the default), a `Natives.Color`, or a `System.Drawing.Color`. |

<ApiRef name="MenuOptionScrollStyle" /> is `LinearScroll`, <ApiRef name="MenuOptionScrollStyle" member="CenterFixed" /> or <ApiRef name="MenuOptionScrollStyle" member="WaitingCenter" />.

Hex colors accept `"#RGB"`, `"#RGBA"`, `"#RRGGBB"` and `"#RRGGBBAA"`; an invalid value logs an error and the color resets to the default.

## Key Binds

<ApiRef name="KeyBind" /> is a `[Flags]` `uint` enum, so several keys can be
combined with `|`:

`Mouse1`, `Mouse2`, `Space`, `Ctrl`, `W`, `A`, `S`, `D`, `E`, `Esc`, `R`, `Alt`, `Shift`, `Weapon1`, `Weapon2`, `Grenade1`, `Grenade2`, `Tab`, `F`.

In WASD input mode (`Menu.InputMode` in `configs/core.jsonc`), key bind overrides do not take effect.

## Option Types

Built-in options live under `SwiftlyS2.Core.Menus.OptionsBase`:

- <ApiRef name="TextMenuOption" />: non-interactive informational line.
- <ApiRef name="ButtonMenuOption" />: clickable action.
- <ApiRef name="ToggleMenuOption" />: per-player on/off value.
- <ApiRef name="SliderMenuOption" />: numeric range with step.
- <ApiRef name="ChoiceMenuOption" />: per-player value from a string list.
- <ApiRef name="InputMenuOption" />: chat input with validation.
- <ApiRef name="ProgressBarMenuOption" />: dynamic progress display.
- <ApiRef name="SubmenuMenuOption" />: opens another menu.
- <ApiRef name="SelectorMenuOption`1" />: typed selector with previous/next
  behavior.

```csharp
var slider = new SliderMenuOption(
    text: "Round Time",
    min: 60f,
    max: 300f,
    defaultValue: 120f,
    step: 30f,
    totalBars: 8
);

slider.ValueChanged += (sender, args) =>
{
    args.Player.SendChat($"Round time: {args.NewValue:0}s");
};

var menu = Core.MenusAPI.CreateBuilder()
    .Design.SetMenuTitle("Player Preferences")
    .AddOption(slider)
    .Build();
```

The other value-holding options (<ApiRef name="ToggleMenuOption" />, <ApiRef name="InputMenuOption" />, <ApiRef name="ChoiceMenuOption" />, <ApiRef name="SelectorMenuOption`1" />) follow the same constructor-plus-`ValueChanged`-handler pattern, just with their own value type (`bool`, `string`, etc. - see <ApiRef name="MenuOptionValueChangedEventArgs`1" member="OldValue" />/<ApiRef name="MenuOptionValueChangedEventArgs`1" member="NewValue" />).

## Submenus

Provide a pre-built submenu, or build it lazily when selected.

```csharp
var advancedMenu = Core.MenusAPI.CreateBuilder()
    .Design.SetMenuTitle("Advanced")
    .AddOption(new ButtonMenuOption("Do advanced action"))
    .Build();

var openAdvanced = new SubmenuMenuOption("Advanced", advancedMenu);

var lazyAdvanced = new SubmenuMenuOption("Lazy Advanced", () =>
{
    return Core.MenusAPI.CreateBuilder()
        .Design.SetMenuTitle("Loaded On Demand")
        .AddOption(new TextMenuOption("This submenu was built on click"))
        .Build();
});
```

## Open and Close Menus

```csharp
Core.MenusAPI.OpenMenuForPlayer(player, menu);
Core.MenusAPI.CloseActiveMenu(player);

Core.MenusAPI.OpenMenu(menu);
Core.MenusAPI.CloseMenu(menu);

Core.MenusAPI.CloseAllMenus();

var current = Core.MenusAPI.GetCurrentMenu(player);
```

Both open methods have an overload taking a callback that runs when the menu is closed for that player:

```csharp
Core.MenusAPI.OpenMenuForPlayer(player, menu, (p, m) => p.SendChat("Menu closed."));
Core.MenusAPI.OpenMenu(menu, (p, m) => p.SendChat("Menu closed for a player."));
```

<ApiRef name="IMenuAPI" member="ShowForPlayer" />/
<ApiRef name="IMenuAPI" member="HideForPlayer" /> only affect visual display -
prefer the manager methods above for full state handling and events.

## Events

### Global manager events

```csharp
public override void Load(bool hotReload)
{
    Core.MenusAPI.MenuOpened += OnMenuOpened;
    Core.MenusAPI.MenuClosed += OnMenuClosed;
}

public override void Unload()
{
    Core.MenusAPI.MenuOpened -= OnMenuOpened;
    Core.MenusAPI.MenuClosed -= OnMenuClosed;
}

private void OnMenuOpened(object? sender, MenuManagerEventArgs args)
{
    if (args.Player != null)
        Core.Logger.LogInformation("Menu opened for {SteamId}", args.Player.SteamID);
}

private void OnMenuClosed(object? sender, MenuManagerEventArgs args) { /* same shape */ }
```

Both handlers receive <ApiRef name="MenuManagerEventArgs" /> (`Player`, `Menu`).

### Per-menu and per-option events

```csharp
var adminOnly = new ButtonMenuOption("Admin Action");

adminOnly.Validating += (sender, args) =>
{
    // args.Player, args.Option are also available here
    if (!Core.Permission.PlayerHasPermission(args.Player.SteamID, "admin"))
    {
        args.Cancel = true;
        args.CancelReason = "You are not an admin.";
    }
};

adminOnly.Click += (sender, args) =>
{
    args.Player.SendChat("Admin action executed.");
    return ValueTask.CompletedTask;
};

adminOnly.BeforeFormat += (sender, args) => args.CustomText = $"[SECURE] {args.Option.Text}";
adminOnly.AfterFormat += (sender, args) => args.CustomText = $"<font color='#FFD700'>{args.CustomText}</font>";

var menu = Core.MenusAPI.CreateBuilder().Design.SetMenuTitle("Admin").AddOption(adminOnly).Build();

menu.OptionHovering += (sender, args) => { /* fired every render frame while hovering */ };
menu.OptionHovered += (sender, args) => { /* fired only when the hovered option changes */ };
menu.OptionSelected += (sender, args) => { /* fired when a selection is activated */ };
```

| Event                                                                                                                                                                 | Event args and notes                                                                                                                       |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| <ApiRef name="IMenuOption" member="Validating" />                                                                                                                     | <ApiRef name="MenuOptionValidatingEventArgs" /> (`Player`, `Option`, settable `Cancel` and `CancelReason`). Runs before `Click`.           |
| <ApiRef name="IMenuOption" member="Click" />                                                                                                                          | <ApiRef name="MenuOptionClickEventArgs" /> (`Player`, plus a read-only `CloseMenu` flag). Asynchronous - return `ValueTask.CompletedTask`. |
| <ApiRef name="IMenuOption" member="BeforeFormat" /> / <ApiRef name="IMenuOption" member="AfterFormat" />                                                              | <ApiRef name="MenuOptionFormattingEventArgs" /> (`Player`, `Option`, settable `CustomText`).                                               |
| <ApiRef name="IMenuOption" member="VisibilityChanged" /> / <ApiRef name="IMenuOption" member="EnabledChanged" /> / <ApiRef name="IMenuOption" member="TextChanged" /> | <ApiRef name="MenuOptionEventArgs" />; `Player` is `null` because these are global property changes.                                       |
| <ApiRef name="IMenuAPI" member="OptionHovering" />                                                                                                                    | <ApiRef name="MenuEventArgs" /> (`Player`, `Options`). Fired once per render frame while an option is hovered - keep the handler cheap.     |
| <ApiRef name="IMenuAPI" member="OptionHovered" />                                                                                                                     | <ApiRef name="MenuEventArgs" /> (`Player`, `Options`). Fired only when the hovered option changes.                                          |
| <ApiRef name="IMenuAPI" member="OptionSelected" />                                                                                                                    | <ApiRef name="MenuEventArgs" /> (`Player`, `Options`). Fired when a selection is activated.                                                 |

`Click` is declared as <ApiRef name="AsyncEventHandler`1" /> - `ValueTask (object? sender, MenuOptionClickEventArgs args)` - the async counterpart of `EventHandler<T>` that the other events use.

## Runtime Updates

```csharp
var option = new ButtonMenuOption("Dynamic Option");
var menu = Core.MenusAPI.CreateBuilder().AddOption(option).Build();

menu.AddOption(new TextMenuOption("Added later"));
menu.MoveToOptionIndex(player, 0);

option.SetVisible(player, false);
option.SetEnabled(player, false);
```

<ApiRef name="IMenuOption" member="Visible" />/
<ApiRef name="IMenuOption" member="Enabled" /> are the global states;
`SetVisible`/`SetEnabled(player, ...)` set per-player values on top of them.
Per-player values have lower priority than the global property, so a globally
hidden or disabled option stays hidden or disabled for every player.

Other <ApiRef name="IMenuOption" /> members you can use while a menu is open:

| Member                                                                                                | Description                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| <ApiRef name="IMenuOption" member="Text" /> / <ApiRef name="IMenuOption" member="Comment" />          | Displayed text and comment. Global - changing them affects what all players see.                                                                    |
| <ApiRef name="IMenuOption" member="Visible" /> / <ApiRef name="IMenuOption" member="Enabled" />       | Global visibility and interaction state.                                                                                                            |
| <ApiRef name="IMenuOption" member="SetVisible" /> / <ApiRef name="IMenuOption" member="GetVisible" /> | Per-player visibility.                                                                                                                              |
| <ApiRef name="IMenuOption" member="SetEnabled" /> / <ApiRef name="IMenuOption" member="GetEnabled" /> | Per-player enabled state.                                                                                                                           |
| <ApiRef name="IMenuOption" member="Tag" />                                                            | Free-form object for your own bookkeeping.                                                                                                          |
| <ApiRef name="IMenuOption" member="LineCount" />                                                      | Number of lines the option occupies (read-only).                                                                                                    |
| <ApiRef name="IMenuOption" member="MaxWidth" />                                                       | Maximum display width of the option text, in relative units.                                                                                        |
| <ApiRef name="IMenuOption" member="TextSize" />                                                       | <ApiRef name="MenuOptionTextSize" />: `ExtraSmall`, `Small`, `SmallMedium`, `Medium`, `MediumLarge`, `Large`, `ExtraLarge`.                         |
| <ApiRef name="IMenuOption" member="TextStyle" />                                                      | <ApiRef name="MenuOptionTextStyle" />: `TruncateEnd`, `TruncateBothEnds`, `ScrollLeftFade`, `ScrollRightFade`, `ScrollLeftLoop`, `ScrollRightLoop`. |
| <ApiRef name="IMenuOption" member="PlaySound" />                                                      | Whether selecting this option plays the selection sound.                                                                                            |
| <ApiRef name="IMenuOption" member="CloseAfterClick" />                                                | Whether the menu closes after the option is clicked (read-only).                                                                                    |
| <ApiRef name="IMenuOption" member="Menu" />                                                           | The menu the option belongs to, or `null` until it is added to one.                                                                                 |

For custom option implementations, <ApiRef name="IMenuOption" /> also exposes

<ApiRef name="IMenuOption" member="GetDisplayText" />
(`player`, `displayLine = 0`),
<ApiRef name="IMenuOption" member="IsClickTaskCompleted" /> (`player`),
<ApiRef name="IMenuOption" member="OnValidatingAsync" /> (`player`, returns
`ValueTask<bool>`) and <ApiRef name="IMenuOption" member="OnClickAsync" />
(`player`, returns `ValueTask`).

## Direct `CreateMenu` Usage

<ApiRef name="IMenuManagerAPI" member="CreateMenu" /> is a lower-level
alternative to the builder, taking explicit <ApiRef name="MenuConfiguration" />/
<ApiRef name="MenuKeybindOverrides" /> objects (the same settings the builder's
`.Design`/`Set*Button` calls configure) instead of a fluent chain:

```csharp
var menu = Core.MenusAPI.CreateMenu(
    new MenuConfiguration { Title = "Raw Menu", MaxVisibleItems = 5 },
    new MenuKeybindOverrides { Select = KeyBind.E, Move = KeyBind.W, MoveBack = KeyBind.S, Exit = KeyBind.Esc },
    parent: null,
    optionScrollStyle: MenuOptionScrollStyle.CenterFixed,
    optionTextStyle: MenuOptionTextStyle.TruncateEnd
);
```

`parent` defaults to `null`, `optionScrollStyle` to

<ApiRef name="MenuOptionScrollStyle" member="CenterFixed" /> and
`optionTextStyle` to <ApiRef name="MenuOptionTextStyle" member="TruncateEnd" />.

### MenuConfiguration

| Member                                                                                         | Default  | Description                                                                                                                            |
| ---------------------------------------------------------------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `Title` (`string`)                                                                             | `"Menu"` | Title displayed at the top.                                                                                                            |
| `HideTitle` / `HideTitleItemCount` / `HideFooter` / `HideComment` (`bool`)                     | `false`  | Hides the title, the item count in the title, the footer or the comments.                                                              |
| `PlaySound` (`bool`)                                                                           | `true`   | Whether interaction sounds play.                                                                                                       |
| `MaxVisibleItems` (`int`)                                                                      | `-1`     | Options visible at once. Valid range `[1, 5]`; out-of-range values log an error and reset to `-1`, which falls back to `ItemsPerPage`. |
| `AutoIncreaseVisibleItems` (`bool`)                                                            | `true`   | Whether hiding the title or footer increases the effective visible item count during rendering.                                        |
| `FreezePlayer` (`bool`)                                                                        | `false`  | Whether player movement is frozen while the menu is open.                                                                              |
| `DisableExit` (`bool`)                                                                         | `false`  | Whether the exit button is disabled for this menu.                                                                                     |
| `AutoCloseAfter` (`float`)                                                                     | `0f`     | Seconds before the menu closes automatically; `0` or less disables auto-close.                                                         |
| `NavigationMarkerColor` / `FooterColor` / `VisualGuideLineColor` / `DisabledColor` (`string?`) | `null`   | Hex colors for navigation markers, footer, visual guide lines and disabled options.                                                    |
| `DefaultComment` (`string`)                                                                    | `""`     | Comment used for options that do not set their own.                                                                                    |
| `ExtraButtons` (`List<MenuExtraButton>`)                                                       | empty    | Extra footer buttons, see <ApiRef name="MenuExtraButton" /> (`KeyBind`, `Label`, `Action`).                                            |

### MenuKeybindOverrides

All four members are `KeyBind?` and default to `null`, which keeps the core default from `Menu.Buttons`:

| Member     | Description                            |
| ---------- | -------------------------------------- |
| `Select`   | Key bind for activating the selection. |
| `Move`     | Key bind for moving forward.           |
| `MoveBack` | Key bind for moving backward.          |
| `Exit`     | Key bind for closing the menu.         |

## Common Pitfalls

- Open and close menus through `Core.MenusAPI` manager methods, not only `ShowForPlayer`/`HideForPlayer`.
- Keep heavy logic out of `OptionHovering` - it runs every render frame while hovering.
- Unsubscribe manager-level events (`MenuOpened`/`MenuClosed`) during plugin `Unload()`.
