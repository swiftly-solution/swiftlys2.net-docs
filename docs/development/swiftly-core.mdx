title: Swiftly Core
---

<ApiRef name="ISwiftlyCore" /> is the central entry point for all plugin
services in SwiftlyS2. `Core` refers to the `ISwiftlyCore` instance every plugin
receives.

## How Core Is Provided

<ApiRef name="BasePlugin" /> takes `ISwiftlyCore` in its constructor and exposes
it as the protected `Core` property, which only that constructor assigns:

```csharp
public sealed class MyPlugin : BasePlugin
{
    public MyPlugin(ISwiftlyCore core) : base(core)
    {
    }

    public override void Load(bool hotReload)
    {
        Core.Logger.LogInformation("Plugin loaded. Hot reload: {HotReload}", hotReload);
    }

    public override void Unload()
    {
        Core.Logger.LogInformation("Plugin unloaded.");
    }
}
```

<Callout type="info">
    Pass `ISwiftlyCore` (or the specific services you need) into helper classes
    rather than reaching for a static/global reference.
</Callout>

| `Core.Logger`, `Core.LoggerFactory`   | Standard `Microsoft.Extensions.Logging` logger                                                                            |

Full member list for any of these: <ApiRef name="ISwiftlyCore" />.

`Core.Menu` is the component-based menu framework described in [Menu System](/docs/development/menu-system). It replaces `Core.MenusAPI`, which is `[Obsolete]` and documented in [Menus](/docs/development/menus) for plugins that still use it.

Runtime paths are exposed on `Core` as well: `Core.PluginPath` (current plugin's directory), `Core.PluginDataDirectory` (per-plugin data directory, created by the framework if needed), `Core.GameFilesDirectory` (`game/csgo`) and `Core.GameDirectory` (game root). `Core.CSGODirectory` points at `game/csgo` too, but it is `[Obsolete]` - use `Core.GameFilesDirectory` instead.

## Thread Awareness

`Core.IsGameThread` reports whether the current call is on the game thread:

```csharp
public void EnsureMainThreadAction(Action action)
{
    if (Core.IsGameThread)
    {
        action();
        return;
    }

    Core.Scheduler.NextTick(action);
}
```

<Callout type="warning">
    Many game-facing APIs are thread-unsafe (`[ThreadUnsafe]`). Off the game
    thread, use their `Async` counterpart or hand the call to `Core.Scheduler`
    first. See [Thread Safety](/docs/development/thread-safety).
</Callout>

## Registering Attribute Handlers on Other Classes

Your plugin class is registered for attribute discovery automatically. Any other class needs `Core.Registrator.Register(instance)` - see [Using Attributes](/docs/development/using-attributes) for a full worked example and the complete attribute list.
